# 在线出题与考试系统开发功能文档

## 总览

- 管理端：`Gin` 开发 REST 接口，使用 `SQLite` 作为内置数据库、`Redis` 作为会话/缓存/限流支持。
- 用户端：微信小程序。支持登录、试卷列表、考试作答、成绩查询、错题本与练习模式。
- 目标：题库与试卷管理、考试流程闭环、自动/人工评分、排名与报表、媒体与代码/公式渲染支持。
- 特点：支持单选/多选/填空/简答题；代码框高亮；数学公式（LaTeX）渲染；图片/视频附件；RBAC 权限；审计日志；防作弊与限流。

## 技术栈与架构

- 服务端：`Go (Gin)` + `SQLite` + `Redis`
  - 认证：小程序端使用微信登录；管理端使用用户名/密码登录，`JWT`/`Session`（Redis 持久）。
  - 权限：`RBAC`（角色-权限-资源）。
  - 缓存：热题、排行榜、会话、限流令牌桶。
  - 存储：题库与考试记录落库到 `SQLite`；媒体文件可先本地磁盘存储，未来可切换对象存储（如 COS/OSS/S3）。
  - 页面：`Vue3 + ElementPlus`（管理端）。开发环境前后端分离；发布时使用 `embed.FS` 将构建产物嵌入二进制并通过静态路由提供，避免路径耦合与跨平台问题。
  - 单机并发考试场景需关注文件锁与磁盘 IO，上线前进行并发提交压测。
  - 会话与限流：Redis 采用前缀化键设计与 TTL 管理（会话、令牌桶、排行榜缓存），配置连接池与断线重试。
- 小程序端：微信小程序
  - 组件：试卷列表、考试页（题目展示、代码框、公式、图片/视频）、成绩页、错题本、排行榜。
  - 渲染：`KaTeX/MathJax`（通过 WebView 或富文本渲染）、代码高亮（前端代码高亮库）。
- 部署：单机可用，后续可升级数据库到 `PostgreSQL/MySQL`，存储迁移至对象存储，服务分层与水平扩展。
- 环境：`dev/staging/prod` 分层，使用环境变量与配置文件加载（数据库、Redis、上传限制、限流、评分策略、可见范围）。敏感配置通过环境变量或安全配置中心注入。

## 数据模型设计（概念）

- 用户（User）
  - 基本信息：`id`、`openid/unionid`（小程序）、`username`（管理端）、`nickname`、`avatar`、`status`（启用/停用）、`level`（等级）、`score`（积分）。
  - 角色：`roles`（admin/teacher/student）。
- 权限（Role/Permission）
  - 角色与权限表：资源与操作（`question:create` 等）。
- 题目（Question）
  - 字段：`id`、`type`（single/multiple/fill/short）、`content`（富文本+公式+图片/视频占位）、`options`（单/多选）、`answer`（标准答案）、`analysis`（解析）、`difficulty`（难度）、`tags`、`version`（题目版本）。
  - 附件：`media[]`（图片/视频 URL）、`codeBlocks[]`（语言、内容）。
- 题库（Bank/Category）
  - 标签与分类管理，支持难度与知识点。
- 试卷（Paper）
  - 字段：`id`、`title`、`description`、`questionRefs[]`（题目引用与分值）、`totalScore`、`duration`（时长）、`visible`（可见范围）、`shuffle`（题序/选项乱序）。
  - 约束：引用的题目需锁定 `version`，发布后试卷内容不可变更，仅允许新增试卷版本。
- 考试（Exam）
  - 字段：`id`、`paperId`、`startTime/endTime`、`status`（未开始/进行中/已结束）、`limit`（参加条件、次数）。
  - 规则：重复参加策略（取最高或最近一次）、人机验证开关与切屏阈值、提交频率限流。
- 答题记录（AnswerSheet）
  - 字段：`id`、`examId`、`userId`、`answers[]`（每题作答与用时、附件）、`autoScore`、`manualScore`、`finalScore`、`submittedAt`、`cheatFlags`（防作弊标记）。
  - 约束：同一用户同一考试的最终提交具备幂等性；草稿与最终提交分开存储，提交动作写审计日志。
- 成绩与排名（Scoreboard）
  - 维度：单次考试排名、历史最佳、平均分、班级/组织维度。
- 媒体资源（MediaAsset）
  - 上传记录：`id`、`type`（image/video）、`url`、`owner`、`hash`、`size`、`createdAt`。
  - 约束：文件名与路径统一规范（按日期/用户/类型分层），去重采用 `sha256`；访问链接加签与有效期控制。
- 审计日志（AuditLog）
  - 所有关键操作：用户管理、题目增删改、组卷、发布、评分。
  - 字段：`id`、`actorId`、`action`、`resourceType`/`resourceId`、`payload`、`ip`、`ua`、`createdAt`、`traceId`。
- 等级与积分（Level/Point）
  - 积分规则：完成考试、满分、连续登录、练习纠错等。

## 管理端功能清单

- 认证与账号
  - `POST /api/admin/auth/register` 管理员/教师注册
  - `POST /api/admin/auth/login` 登录（JWT/Session）
  - `POST /api/admin/auth/logout` 退出
  - `GET /api/admin/auth/profile` 个人信息
  - 支持强密码策略、登录失败锁定、两步验证（可选）
  - 登录响应携带 `traceId`，后续接口通过请求头传递，便于审计与排障。
- 用户管理
  - `GET /api/admin/users` 列表/搜索/分页
  - `POST /api/admin/users` 增加用户（分配角色/等级）
  - `PATCH /api/admin/users/:id` 更新（头像、昵称、等级、状态）
  - `DELETE /api/admin/users/:id` 删除/停用
  - 批量导入/导出（`CSV/Excel/JSON`）
- 题目管理
  - `GET /api/admin/questions` 列表/搜索/分页/按标签与难度过滤
  - `POST /api/admin/questions` 新增题目（支持富文本、代码块、公式、图片/视频）
  - `PATCH /api/admin/questions/:id` 更新题目（版本化）
  - `DELETE /api/admin/questions/:id` 删除题目（软删+审计）
  - 选项乱序开关、答案校验、解析维护
  - 题目版本管理：更新需创建新版本；已发布试卷引用旧版本保持不变。
- 试卷管理
  - `GET /api/admin/papers` 列表/搜索
  - `POST /api/admin/papers` 创建试卷（手动/按规则随机组卷）
  - `PATCH /api/admin/papers/:id` 更新（分值、时长、乱序、可见范围）
  - `POST /api/admin/papers/:id/publish` 发布/撤销发布
  - 发布后生成只读快照（包含题目内容与分值），供考试与成绩详情使用。
- 考试管理
  - `GET /api/admin/exams` 列表
  - `POST /api/admin/exams` 创建考试（绑定试卷、时间窗、参加限制）
  - `PATCH /api/admin/exams/:id` 更新
  - 防作弊：题序/选项乱序、切屏次数记录、拍照/摄像头（可选）、IP/地理限制（可选）
  - 提交幂等：提交接口支持 `Idempotency-Key`，避免网络重试导致重复计分。
- 成绩管理
  - `GET /api/admin/scores` 成绩列表、导出
  - `GET /api/admin/exams/:id/scoreboard` 排名与统计
  - 自动评分：客观题（单选/多选/填空）
  - 人工评分：主观题（简答），评分标准、双评仲裁
  - 部分得分：多选/填空支持部分正确计分
  - 得分精度与四舍五入统一（可配置），避免累计误差。
- 媒体与附件管理
  - `POST /api/admin/media/upload` 上传图片/视频（大小限制、类型校验、病毒扫描可选）
  - `GET /api/admin/media` 媒体库
  - CDN/分片上传/断点续传（可选）
  - 图片/视频元信息抽取（宽高/时长）入库，便于前端渲染与限制校验。
- 标签与分类
  - `GET/POST/PATCH/DELETE /api/admin/tags`、`/categories` 管理
- 消息与通知
  - 考试发布/开始/结束通知；成绩出炉通知；系统广播（可选）
- 系统配置
  - 考试策略、限流、上传限制、缓存策略、评分规则、可见范围等配置项
  - 配置变更写审计日志，支持灰度发布与回滚。
- 审计与日志
  - 操作审计、系统日志、告警与告警订阅（邮件/钉钉/企业微信可选）
  - 请求级 `traceId` 与统一日志格式（时间、level、traceId、actor、路由、耗时、结果码）。
- 导入与导出
  - 题目与成绩的 `CSV/Excel/JSON` 导入/导出；错误报告与回滚
  - 大批量导入采用任务队列与进度查询；失败项导出供修复后重导。

## 用户端（小程序）功能清单

- 登录与绑定
  - 微信登录（`code` 换取 Session），新用户自动注册或绑定到已有账号
  - 使用 `openid` 作为主键，`unionid` 作为跨应用标识（如可用）；会话有效期与续期阈值明确，支持主动注销与后台踢出。
- 个人中心
  - 查看与更新头像/昵称；等级与积分；最近考试与成绩
- 试卷列表
  - 可见试卷分页；搜索/标签/难度筛选；考试时间窗展示
- 考试作答
  - 题目渲染：单选/多选/填空/简答；富文本/图片/视频；数学公式；代码块高亮
  - 行为：自动保存草稿；倒计时；网络断线重试；选项乱序；填空支持多个空
- 防作弊提示：切屏警告；超过阈值自动标记
  - 弱网与断线：本地缓存草稿并重试上报；提交前展示幂等提示与最终确认。
- 成绩与详情
  - 成绩列表；单次详情（每题得分与解析）；错题本（收藏/再练）
- 练习与错题
  - 练习模式（不限时）；智能组题（基于错题与难度）
- 排行榜与勋章（可选）
  - 全站、班级、考试维度排行榜；勋章与等级规则
- 消息通知（可选）
  - 新考试、成绩发布、小程序订阅消息

## 题型与渲染支持

- 单选/多选
  - 选项支持富文本与图片；多选评分支持部分得分；选项乱序（服务端生成）。
  - 多选评分策略：支持“错选惩罚/不惩罚”两模式，由试卷配置决定。
- 填空
  - 支持多个空；答案匹配策略（严格/忽略大小写/去空格/正则）；部分得分；容错词库（可选）。
- 简答
  - 支持富文本、公式、代码块；人工评分；评分标准与示例答案。
- 代码框
  - 语言选择（如 `go/js/py/java/cpp`）；行号/复制；只读或可编辑（题目要求）；可选“运行”按钮（后端沙箱待选）。
  - 代码块大小与语言白名单限制；长代码折叠与复制按钮。
- 数学公式
  - `LaTeX` 存储；前端用 `KaTeX/MathJax` 渲染；支持内联与块级。
- 媒体
  - 图片/视频（大小/时长限制）；预览与全屏；加载占位与失败重试。
  - 图片懒加载与错误占位；视频支持倍速与进度保存（可选）。

## 打分与排名规则

- 自动评分
  - 单选：完全匹配得分
  - 多选：完全匹配满分；部分匹配按比例得分（可配置是否惩罚错选）
  - 填空：按空位逐一评分；支持多参考答案与正则
  - 统一空白/大小写处理策略，支持去空格与中英文符号等价映射（可选）。
- 主观题评分
  - 单人/双人评分；评分标准（rubric）；差异仲裁；可选 AI 辅助打分（离线评审）
  - 阅卷流程：任务分配、打分提交审计、差异阈值触发二评与仲裁。
- 时间与惩罚
  - 超时提交：不允许或按比例扣分（可配置）
  - 重复提交：取最高/最近一次（可配置）
  - 迟交窗口与缓交策略（可选），明确用户端提示与服务端校验。
- 排名维度
  - 单次考试、历史最佳、平均分、速度（用时）、等级
  - 并列分数处理与排序稳定性（同分按用时或提交时间排序）。

## 安全与合规

- 认证与权限
  - 管理端：JWT/Session（Redis），密码加盐哈希；角色/权限校验中间件
  - 用户端：微信登录态校验；服务端 session 续期与踢出
  - 管理端 CSRF 与 CORS 配置；密码强度与登录失败锁定阈值明确。
- 防作弊与风控
  - 乱序；切屏计数；设备/IP/地理位置校验（可选）；人机验证（图形/滑块/短信可选）
  - 限流与防刷：登录/提交接口令牌桶；Redis 计数
  - 提交窗口限速与异常行为告警（短时多次重复提交/切屏）。
- 数据安全
  - 敏感字段脱敏；媒体/导出链接加签有效期；数据备份与恢复；日志留存与合规（GDPR/隐私）
  - 最小化权限原则（RBAC）；管理员操作双因子验证（可选）；导出数据脱敏模板。

## 性能与扩展

- 缓存策略
  - 题库与试卷元数据缓存；排行榜缓存；热题预加载
  - 试卷快照与成绩详情预计算，避免高峰期频繁聚合查询。
- 搜索与分页
  - 服务端分页与索引；关键词搜索（题干/标签）；批量查询优化
  - 统一分页入参（`page`、`pageSize`）与出参（`list`、`total`），支持排序与多字段过滤。
- 上传与大文件
  - 分片与断点续传（前端直传到对象存储，后端回调）
- 迁移与扩展
  - 数据库从 `SQLite` 平滑迁移到 `PostgreSQL/MySQL`；对象存储与 CDN 引入
  - 迁移策略：双写/校验、数据一致性比对、灰度切换与回滚预案。

## 接口设计约定（示例）

- 统一响应结构
  - 成功：`{ code: 0, data: ..., message: "ok" }`
  - 失败：`{ code: <非0>, message: "错误描述", detail?: {} }`
- 接口版本与路径
  - 管理端与小程序端统一版本前缀（如 `/api/v1/admin/...`、`/api/v1/mp/...`），便于演进与兼容。
- 错误码与码值
  - 认证类：`100xx`；权限类：`110xx`；业务类：`200xx`；媒体类：`300xx`
- 分页与过滤约定
  - 入参：`page`、`pageSize`、`sortBy`、`sortOrder`、`filters`；出参：`list`、`total`、`page`、`pageSize`。
- 幂等与重试
  - 关键写操作（提交、发布、导入）支持幂等键与重复请求安全处理；返回 `Retry-After` 或限流头部。
- 追踪与时间
  - 请求/响应包含 `X-Request-ID` 或 `traceId`；时间统一使用 UTC ISO8601，客户端按时区展示。
- 管理端主要路由（示例）
  - `POST /api/admin/auth/login`、`POST /api/admin/auth/logout`、`GET /api/admin/auth/profile`
  - `GET/POST/PATCH/DELETE /api/admin/users`
  - `GET/POST/PATCH/DELETE /api/admin/questions`
  - `GET/POST/PATCH/DELETE /api/admin/papers`
  - `GET/POST/PATCH /api/admin/exams`
  - `GET /api/admin/exams/:id/scoreboard`、`GET /api/admin/scores`
  - `GET/POST /api/admin/media`
- 小程序主要路由（示例）
  - `POST /api/mp/auth/login`（微信 `code` 换会话）
  - `GET /api/mp/papers`、`GET /api/mp/exams`
  - `POST /api/mp/exams/:id/submit`（断点续传/自动保存支持）
  - `GET /api/mp/scores`、`GET /api/mp/scores/:id`
  - `GET /api/mp/me`、`PATCH /api/mp/me`

## 测试与质量保障

- 后端测试：单元测试（题型评分、乱序、权限中间件）、集成测试（接口流）、基准测试（评分与榜单）
- 前端测试：关键渲染（公式、代码块）、交互（选择/填空）、网络异常恢复
- 压测：并发考试提交与成绩计算；媒体上传并发；Redis 命中率
- 质量：Lint/格式化；API 契约与 Mock；灰度与回滚
- 构建与发布：管理端前端开发阶段独立运行；发布时嵌入后端二进制；统一 CI 流水线执行测试、构建、产物发布与部署。
- 测试数据：提供基础题库/试卷/考试种子数据，便于联调与演示。

## 部署与运维

- 配置：环境变量与配置文件（数据库、Redis、上传限制、限流、评分策略）
- 日志：结构化日志；审计日志；异常告警（邮件/IM）
- 备份：数据库定期备份；媒体与对象存储生命周期管理
- 监控：接口 QPS/错误率/时延；资源使用；考试高峰预警
- 运行参数：`SQLite` WAL 与 `busy_timeout`、连接池大小、Redis 超时与重试；进程优雅停机与健康检查路由。
- 安全：跨域与 CSRF 配置、静态资源缓存策略、上传目录权限与定期清理任务。

## MVP 范围与里程碑

- MVP（第一阶段）
  - 管理端：登录、用户与题目基础 CRUD、试卷创建与发布、考试创建、客观题自动评分、成绩列表与排名、媒体上传基础
  - 小程序：登录、试卷列表、考试作答（四类题型渲染）、成绩列表与详情、错题本（基础）
  - 完成标准：接口联调通过、基础并发压测达标（提交 QPS 与时延）、日志与审计可用、部署与回滚预案齐备。
- 第二阶段
  - 主观题人工评分与评分标准；部分得分策略细化；标签与难度完善；导入/导出；审计日志
  - 完成标准：评分流程闭环、导入大批量任务稳定、配置中心上线。
- 第三阶段
